What the model names mean

A model name like llama3.2:3b breaks down as:

  • llama3.2 — the model family (the architecture, like an engine type)
  • 3b — the size: roughly 3 billion parameters. Bigger usually means smarter, but slower and more memory-hungry

Common sizes

SizeWhat it meansGood for
1b – 3bSmall, fast, runs on almost anythingShort emails, simple rewrites, brainstorming
7b – 8bSolid all-rounderStories, articles, letters, editing
12b – 14bStronger writing, needs more memoryLonger fiction, careful editing
32b+Very strong, needs a powerful computerComplex writing projects (if your computer can handle it)

Recommended starter models

Pull any of these with ollama pull <name>:

ModelBest forApproximate download
llama3.2:3bFast everyday writing, emails, short drafts~2 GB
llama3.2:1bVery fast, older or slower computers~1.3 GB
phi3:miniMicrosoft's small model, good at following instructions~2.3 GB
mistral-nemo:12bStronger storytelling and editing~9 GB
llama3.1:8bPopular, capable all-rounder~4.7 GB

How to choose

  1. Start small. llama3.2:3b or phi3:mini downloads quickly and runs on most computers.
  2. Try it. Run a prompt you actually care about — a scene, a letter, a blog intro.
  3. Upgrade if you need to. If the writing feels too simple, pull a bigger model like mistral-nemo:12b and try the same prompt again.

You can have as many models installed as your hard drive can hold. Switching between them is just a new ollama run command.

Running and managing models

Start a chat:

ollama run llama3.2:3b

Or send one prompt:

ollama run phi3:mini "Rewrite this sentence to be warmer: I am writing to inform you that your application was received."

Useful commands

  • ollama list — list models installed on your computer
  • ollama rm llama3.2:1b — remove a model to free space
  • Browse all available models at ollama.com/library

Memory tips

  • Close heavy apps (web browsers with many tabs, video editors) before running larger models.
  • If your computer gets hot or loud, that is normal — it is working hard. Switch to a smaller model if it bothers you.
  • Models stay on your computer after you download them. You do not need internet to write with them.
